## Part 1 — One-Time Setup on Your Machine

Only needed once, on the Windows PC you'll work from.

### 1.1 Install Google Cloud SDK

Download and install from https://cloud.google.com/sdk/docs/install

### 1.2 Log in

```bash
gcloud auth login
```

A browser opens — sign in as **sales@buzztrackers.com**.

### 1.3 Point at the project

```bash
gcloud config set account sales@buzztrackers.com
gcloud config set project voter-analytics-2026
```

### 1.4 Verify

```bash
gcloud config list
gcloud compute instances list
```

You should see `voter-vm` listed.

### 1.5 Allow your internet connection through the firewall

The firewall only permits **one** IP address. It is currently set to the office IP as of
2026-07-25. If you connect from a different network — or your broadband IP changes —
you must update it or the page will simply not load.

Find your current public IP at https://ifconfig.me then run:

```bash
gcloud compute firewall-rules update allow-streamlit-8501 --source-ranges=YOUR_IP_HERE/32
```

To check what it's currently set to:

```bash
gcloud compute firewall-rules describe allow-streamlit-8501
```

> **Why it's locked to one IP:** the Streamlit app has no login screen and handles voter
> personal data. Do not change this to `0.0.0.0/0` — that exposes the full voter database
> to the public internet.

## Part 2 — Daily Use

The VM already has everything installed. This is the normal day-to-day routine.

### 2.1 Start the VM

```bash
gcloud compute instances start voter-vm --zone=asia-south1-a
```

Takes about 30 seconds. Confirm the external IP hasn't changed:

```bash
gcloud compute instances list
```

> If `EXTERNAL_IP` is no longer `34.180.31.186`, use the new one in the URL below.
> (To make it permanent, see [Reserve a static IP](#reserve-a-static-ip-optional).)

### 2.2 SSH into the VM

```bash
gcloud compute ssh User@voter-vm --zone=asia-south1-a
```

> **Always include `User@`.** Without it, gcloud uses your Windows username to create a
> *new* Linux account with an empty home directory, and none of the installed files will
> be there.

### 2.3 Start the app

```bash
sudo systemctl start voter-analytics-2
sudo systemctl status voter-analytics-2
```

Look for `Active: active (running)`.

If you ran `sudo systemctl enable voter-analytics-2` previously, the app starts
automatically whenever the VM boots and you can skip this step.

### 2.4 Open the web UI

http://34.180.31.186:8501

### 2.5 Stop the VM when done

Shutting the VM down stops all billing for compute. Your uploads, output files, and
checkpoints are preserved on disk.

```bash
gcloud compute instances stop voter-vm --zone=asia-south1-a
```

## Part 4 — Full Setup on a Brand New VM

Only needed if you're building a second VM or rebuilding this one from scratch.

### 4.1 Create the VM

```bash
gcloud compute instances create voter-vm-2 --zone=asia-south1-a --machine-type=e2-standard-8 --image-family=ubuntu-2204-lts --image-project=ubuntu-os-cloud --boot-disk-size=100GB
```

Two warnings appear (disk under 200 GB, disk larger than image). Both are safe to ignore —
Ubuntu expands the partition automatically on first boot.

### 4.2 Open the firewall

If the `allow-streamlit-8501` rule already exists you can skip this — one rule covers all
VMs in the project.

```bash
gcloud compute firewall-rules create allow-streamlit-8501 --allow tcp:8501 --direction INGRESS --source-ranges=YOUR_IP_HERE/32
```

### 4.3 SSH in

```bash
gcloud compute ssh User@voter-vm-2 --zone=asia-south1-a
```

### 4.4 Run the installer

```bash
curl -sSL https://raw.githubusercontent.com/thiraviyalingesh/voters_project_2.0/main/cloud/setup.sh | tr -d '\r' | bash -s -- --port 8501
```

Takes about 5 minutes. It performs 7 steps:

1. Updates apt packages
2. Installs Tesseract OCR + Tamil and English language packs, poppler, OpenCV libs
3. Clones the repo to `~/voter_analytics_2.0` and creates the working directories
4. Creates a Python virtual environment
5. Installs streamlit, pymupdf, pytesseract, pillow, openpyxl, requests, watchdog, pandas, matplotlib
6. Writes the `voter-analytics-2` systemd service
7. Configures ufw

It finishes with a verification block. Confirm you see:

```
Tesseract languages:
eng
tam
[✓] Tamil & English language packs installed
```

> The `tr -d '\r'` is required — it strips Windows line endings that would otherwise break
> the bash script.

### 4.5 Enable and start

```bash
sudo systemctl enable --now voter-analytics-2
sudo systemctl status voter-analytics-2
```

`enable` makes it start automatically on every reboot. `--now` starts it immediately.

### 4.6 Get the IP and open

```bash
curl -s ifconfig.me
```

Then browse to `http://<that-ip>:8501`.

## Common Operations

All of these run **inside the VM** unless stated otherwise.

### View live logs

```bash
journalctl -u voter-analytics-2 -f
```

Press `Ctrl+C` to exit. For the last 50 lines instead:

```bash
journalctl -u voter-analytics-2 -n 50 --no-pager
```

### Processing logs

```bash
tail -f ~/voter_analytics_2.0/logs/*.log
```

### Restart the app

```bash
sudo systemctl restart voter-analytics-2
```

### Stop the app (without stopping the VM)

```bash
sudo systemctl stop voter-analytics-2
```

### Reset a stuck "processing" status

Use when the UI says processing is running but nothing actually is (usually after a crash
or an abrupt VM stop):

```bash
echo '{"processing": false, "current_constituency": null, "pid": null, "queue": [], "completed": [], "errors": []}' > ~/voter_analytics_2.0/.processing_status.json
sudo systemctl restart voter-analytics-2
```

The Streamlit UI also has a **Reset Stuck Status** button that does the same thing.

### Check disk space

```bash
df -h /
du -sh ~/voter_analytics_2.0/uploads/*
```

PDF extraction generates a large number of temporary card images. If the disk fills up,
clear old constituency folders you've already exported:

```bash
rm -rf ~/voter_analytics_2.0/uploads/CONSTITUENCY_NAME
```

### Download output Excel files to your PC

Run from Windows, not inside the VM:

```bash
gcloud compute scp User@voter-vm:/home/User/voter_analytics_2.0/uploads/output/*.xlsx D:\downloads\ --zone=asia-south1-a
```

### Upload a file to the VM

```bash
gcloud compute scp LOCALFILE User@voter-vm:/home/User/voter_analytics_2.0/ --zone=asia-south1-a
```

> On Windows, `~` does not work in scp paths — always write out `/home/User/...` in full.

## Resize the VM (Faster OCR)

Upgrading to 8 vCPU roughly doubles OCR throughput. Nothing needs reinstalling — all data
and configuration survives.

```bash
gcloud compute instances stop voter-vm --zone=asia-south1-a
gcloud compute instances set-machine-type voter-vm --zone=asia-south1-a --machine-type=e2-standard-8
gcloud compute instances start voter-vm --zone=asia-south1-a
```

To go back down, use `--machine-type=e2-standard-4`.

## Reserve a Static IP (Optional)

By default the external IP changes each time the VM is stopped and started, which means
re-checking the IP every morning. To pin it permanently:

```bash
gcloud compute addresses create voter-vm-ip --region=asia-south1
gcloud compute instances delete-access-config voter-vm --zone=asia-south1-a --access-config-name="external-nat"
gcloud compute instances add-access-config voter-vm --zone=asia-south1-a --access-config-name="external-nat" --address=voter-vm-ip
```

A reserved IP costs a small amount while the VM is stopped (roughly ₹0.50/hour), so
release it if the project is paused for a long period:

```bash
gcloud compute addresses delete voter-vm-ip --region=asia-south1
```

## Troubleshooting

### Web page won't load / connection times out

Check in this order:

1. **Is the VM running?**
   ```bash
   gcloud compute instances list
   ```
2. **Has the IP changed?** Compare `EXTERNAL_IP` above against the URL you're using.
3. **Is your own IP still allowed?** This is the most common cause. Check https://ifconfig.me
   and compare against:
   ```bash
   gcloud compute firewall-rules describe allow-streamlit-8501
   ```
   Update if different:
   ```bash
   gcloud compute firewall-rules update allow-streamlit-8501 --source-ranges=YOUR_IP_HERE/32
   ```
4. **Is the service running?** SSH in and run:
   ```bash
   sudo systemctl status voter-analytics-2
   ```

### Service won't start

```bash
journalctl -u voter-analytics-2 -n 50 --no-pager
```

Common causes:

| Error in log | Fix |
|---|---|
| `tesseract is not installed or it's not in your PATH` | The systemd `PATH` is wrong. Re-run `setup.sh`. |
| `No such file or directory: .../cloud` | Install directory doesn't match the service. Re-run `setup.sh`. |
| `Address already in use` | Something else holds port 8501: `sudo fuser -k 8501/tcp` then restart. |

### Large PDF upload fails

Streamlit's default upload cap is 200 MB. The service is configured to run from the
`cloud/` directory so it picks up `cloud/.streamlit/config.toml`, which raises the limit to
5000 MB. If uploads are failing at 200 MB, the service is running from the wrong directory —
check that `WorkingDirectory` ends in `/cloud`:

```bash
systemctl cat voter-analytics-2
```

### Out of disk space

```bash
df -h /
```

Clear processed constituency folders (see [Check disk space](#check-disk-space)), or grow
the disk:

```bash
gcloud compute instances stop voter-vm --zone=asia-south1-a
gcloud compute disks resize voter-vm --zone=asia-south1-a --size=200GB
gcloud compute instances start voter-vm --zone=asia-south1-a
```

Then inside the VM:

```bash
sudo growpart /dev/sda 1
sudo resize2fs /dev/sda1
```

### Processing is very slow

Check CPU saturation while a job runs:

```bash
htop
```

All cores pinned at 100% is normal and expected — OCR is CPU-bound. If you need it faster,
see [Resize the VM](#resize-the-vm-faster-ocr).

## Cost Control

Compute is billed only while the VM is **running**. Stopping it leaves you paying just for
the 100 GB disk (a small monthly amount).

**Always stop the VM at the end of the day:**

```bash
gcloud compute instances stop voter-vm --zone=asia-south1-a
```

Approximate rates (asia-south1):

| Resource | Cost |
|---|---|
| `e2-standard-4` running | ~₹11/hour |
| `e2-standard-8` running | ~₹22/hour |
| 100 GB disk (VM stopped or running) | ~₹340/month |
